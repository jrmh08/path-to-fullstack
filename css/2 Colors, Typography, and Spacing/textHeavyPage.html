What is this page all about

This page is all about practicing Colors, Typography and Spacing using CSS. This page is part of my practice in the fundamentals of CSS: color, typography, and spacing. I built it as a text-heavy page to test how far good typography can carry a design when there are no images or complicated layouts, only words. I used the Varela Round font from Google Fonts, kept the line-height consistent, and set deliberate spacing so the text stays easy to read from start to finish. Instead of using many colors, I limited myself to a small palette of a background, an accent, and a text color, and I stored them as CSS variables. That way the three theme buttons on the side (brown, green, and blue) can swap the whole look of the page at once without rewriting any styles. I’m doing this exercise because these basics are what every layout depends on. If I can’t make a plain page of text look clean and readable, fancy effects won’t make up for it. Each choice here, from the font weights to the padding and margins, is practice for building pages that are consistent, accessible, and comfortable to read.

Beyond the assignment itself, this page is a way for me to learn by building instead of only reading. Every time I changed a color, adjusted a margin, or switched a font weight from 400 to 700, I could see the result right away, and that quick feedback is what makes the concepts stick. I also ran into real problems along the way, like a swatch that wouldn’t line up with its label, and fixing them taught me more about how elements actually behave than any tutorial could. I see this page as a foundation. As I keep learning, I want to look back at it and see how much my understanding of layout, spacing, and design has grown.
